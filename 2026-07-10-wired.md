## 100x patterns
- Workflows > demos. Verification is the bottleneck now, not generation.
- **Skills beat prompts** — devs are packaging entire pipelines (build, test, version, release notes, git ops) into one repo-local skill, one command. That's leverage, not chat.
- Memory tied to git state instead of vibes — agents that remember via your actual repo history are the ones people trust past week one.
- Pattern to steal: never clone-and-run blind. Read the README with your own eyes before you let an agent "set up the workspace." GhostApproval exists because nobody does this anymore.
