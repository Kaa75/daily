## News cycle — the pattern that should worry you
Three "sandboxed" tools got cracked this week, same failure class, three different vendors:
- **Cursor IDE — DuneSlide** (CVE-2026-50548/50549, CVSS 9.8): zero-click. A prompt injection hidden in an MCP response or search result sets the LLM-controlled `working_directory` param outside the project root, overwrites the sandbox binary itself, converts "sandboxed" into full unsandboxed RCE. No click needed.
- **n8n** (CVE-2026-25049, CVSS 9.4): expression sandbox escape via type confusion — and it's a **bypass of the patch for a previous sandbox escape** (CVE-2025-68613). "Fixed" didn't mean fixed.
- **Azure OpenAI** (CVE-2026-45499, CVSS 9.9): SSRF elevation-of-privilege in the managed cloud path.
Pattern, not coincidence: any tool that lets an LLM set a parameter that later touches the filesystem or network is a sandbox-escape candidate, and "patched last month" is not a permanent state.

First deceleration signal. Don't over-read one data point, but don't ignore it either — track the next two weeks before recalibrating your "specialize or die" read.

- **LLM-controlled parameters are the new injection surface, full stop.** Before you wire any tool/agent that lets a model set a path, URL, or command arg, ask "what does this touch downstream" — that's the DuneSlide/n8n/Azure lesson in one sentence, reusable across every stack you build.

## The meta
Same week: the biggest open-weight model on the planet ships a day early, and three separately-built "sandboxes" — an IDE, a workflow engine, a hyperscaler's managed API — get cracked by the identical bug class. Self-hosting your own infra (the thing pitched two days ago as the safe move) didn't save n8n. Nothing is sandboxed as hard as its vendor claims. That's not pessimism, that's the actual shape of the job: you get frontier power free-and-early, and every box anyone tells you is sealed is a box you should still assume leaks.
