## Tools & agents
- Claude Code ships `Tool(param:value)` deny/ask rules — scope permissions per-argument now (e.g. `Agent(model:opus)`). Old way: allow the whole tool or nothing. New way: surgical.
- `/cd` command — jump a running session to a new working dir mid-conversation, no prompt cache rebuild. Small, saves real minutes daily.
- Google Antigravity — agent-first IDE, shipped at I/O 2026. Another agent-native editor entering the ring alongside Cursor, Claude Code, Copilot.

GPT-5.6 (Sol/Terra/Luna), Grok 4.5 (1.5T-param MoE, trained on Cursor interaction data, 83.3% on Terminal-Bench 2.1 using ~25% of Opus 4.8's output tokens for the same tasks), Kimi K3 (2.8T-param open-weight, 1M ctx) — all dropped within weeks of each other. ## Features

- Chrome integration out of beta — Claude runs in-browser now, no extension gymnastics.

## News cycle — the ugly part
- **GhostApproval** (Wiz, disclosed July 8): symlink flaw in six AI coding agents — Claude Code, Cursor, Amazon Q, Google Antigravity, Augment, Windsurf. A malicious repo drops a symlink named `project_settings.json` that really points at `~/.ssh/authorized_keys`. The agent's own internal reasoning KNOWS it's writing to your SSH file — the approval prompt shows you the fake name anyway. You click yes, attacker's key lands in your login file. Amazon, Google, Cursor shipped fixes. **Anthropic disputes it's a bug.** Translation: Claude Code may still be exposed right now. Don't blind-approve file writes on repos you didn't write yourself.
- **PolinRider** (North Korea, ongoing since spring, still active): 108 malicious packages across npm, Packagist, Go modules, and one Chrome extension. Method: hijack existing trusted maintainer accounts, not sketchy new packages. Payload hunts for `postcss.config.mjs`, `tailwind.config.js`, `eslint.config.mjs`, `babel.config.js`, `app.js` and silently appends malicious JS. 1,951 GitHub repos already popped, 1,047 owners hit. Check lockfile diffs before you `npm i` blind.

## 100x patterns
- Per-arg permission scoping (`Tool(param:value)`) = stop babysitting approval prompts for safe subcommands, keep the leash tight on the dangerous ones. Configure once, save clicks forever.
- Model triage: cheap/fast tier (Luna/Haiku-class) for grunt work, frontier tier (Sol/Opus/Sonnet 5) only when the task actually needs it. Cost arbitrage = more runs per day = more shots on goal.

## The meta
Symlinks are a decades-old Unix trick, older than most people writing code today, and it just owned six brand-new AI coding agents in 2026 because nobody re-checked the trust boundary when they bolted an LLM onto a shell. You build the future and you're also first in line to get hit by it. That tension isn't a bug in this career choice. That IS the career.
