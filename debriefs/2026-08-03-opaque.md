## Tools & agents
- **Thinking Machines shipped Inkling-Small** (Jul 31) — 276B MoE, only 12B active params (vs the full Inkling's 41B), and it lands within one point of full Inkling on Artificial Analysis's Intelligence Index at roughly a quarter the active-param cost. Apache 2.0, full weights on Hugging Face, fine-tuning wired through their Tinker API. If you already run Inkling for cost reasons, this is a straight downgrade-the-bill move with almost no quality loss.
- **GitHub Copilot CLI v1.0.77** (Jul 30) — unconditional autopilot approval now disables the sandbox for that session when bypass is allowed, `Ctrl+G` opens your editor for freeform `ask_user` answers without killing the prompt, browser-based OAuth login is now the default on local terminals (device code stays default on headless), and macOS/Windows native MDM can now enforce sandbox policy org-wide. Small release, but the MDM sandbox enforcement is the one that matters if you're an admin — it's the first real lever to stop someone quietly running Copilot CLI unsandboxed on a managed machine.

## AI news
- **OpenAI teased "Astra" with zero press release** (Aug 1) — a new multi-agent model family built to grind on a single hard problem for hours or days, not turns. Announcement method: they just pushed ten machine-checkable Lean proofs of decade-old unsolved math and theoretical-CS problems straight to GitHub and let people find them. Same week, Altman privately demoed it to sitting senators (Warnock, Moreno, Warner) in DC — before the model has a public name, a release date, or even a decision on whether it ships as GPT-6 or GPT-5.7. It's also reportedly the first model slated to go through the new classified frontier-capability review process that had its first compliance deadline Aug 1. Read that order again: closed-door government briefing came before the public got a name.

## News cycle — the tools you run are the attack surface, again
- **DeepJack — third distinct Cursor RCE chain this summer.** Nested `cursor://` deeplinks plus whitespace-padded arguments push a malicious MCP-install command off-screen in Cursor's confirm dialog — you see a clean prompt, approve it, and a second hidden `mcp/install` URI (nested inside a `pr-review` URL param Cursor never recursively decodes) fires instead. One click, unsandboxed RCE, still reproducible in build 3.9.8. Same lesson as DuneSlide and Kiro's CVE-2026-10591 before it, third vendor-specific instance of the identical root cause: any confirm dialog an LLM can help construct is a UI you can't fully trust to show you what you're actually approving.
- **JadePuffer's ransomware agent leveled up — it now hunts AI infrastructure specifically.** New companion payload "EncForge" targets training datasets, vector databases, and model checkpoints instead of just app databases. The first agentic ransomware operation (disclosed by Sysdig in July) didn't stay static — three weeks later it specialized in eating the exact assets an AI team would consider irreplaceable. If your vector DB or checkpoint storage isn't in your backup/ransomware threat model yet, it needs to be this week.

## 100x patterns
- **Swap Inkling for Inkling-Small on anything cost-sensitive.** Quarter the active params, ~1 point of quality lost on the intelligence index — that's a bill cut most teams should take without debate.
- **If you admin a fleet running Copilot CLI, wire up the MDM sandbox policy today.** It's the first org-level control that actually stops someone toggling autopilot-bypass on a managed machine — five-minute policy push, real reduction in blast radius.
- **Treat every agentic-IDE confirm dialog as untrusted until you've read the raw payload, not the rendered summary.** DeepJack, DuneSlide, and Kiro's CVE-2026-10591 are three separate vendors hit by the same UI-trust gap in one summer — that's not bad luck, that's a class of bug you should now pattern-match on sight.
- **Back up vector DBs and model checkpoints like you'd back up prod, because ransomware operators just decided they're worth targeting by name.** EncForge existing at all means "AI assets" is now a line item in someone's attack playbook, not just yours.

## The meta
The most capable model announced this week didn't get a launch post — it got a closed-door briefing to three senators and ten GitHub commits nobody would notice unless they were watching. That's not marketing restraint, that's a company routing its most powerful thing through the room with the power to regulate it before the room with the credit card. Meanwhile the same week, a ransomware agent that was a novelty six weeks ago specialized itself, unprompted by any human roadmap, into eating the exact infrastructure you'd build to run something like Astra. Nobody planned either of those trajectories on the same calendar. They just both happened, because the tools compound in both directions at once — capability and threat, same rate, same summer. You're not paranoid for noticing. You're behind if you didn't.
