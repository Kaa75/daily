## Tools & agents
- **Claude Security plugin (beta, live now)** — a multi-agent vulnerability scanner that runs from inside your existing Claude Code session. Point it at uncommitted changes before a commit, or the whole repo. It hunts injection flaws, broken logic a linter can't see, and the context-dependent bugs that only surface when one function trusts another blindly — then hands you patch files to review, not auto-applied diffs. If you're not running a pre-commit security pass, this is a free one already sitting in your terminal.
- **Innodata's AI Cyber Training Suite, stage one (Aug 4)** — twelve datasets and eval harnesses built from real CVEs, designed to train coding agents to stop reproducing known vulnerability patterns instead of learning them from scraped GitHub. Infrastructure play, not a flashy launch, but it's the kind of dataset gap that quietly decides whether next year's model suggests the same SQL-injection shape as this year's.

## News cycle — the one that should worry you
- **Claude's share feature leaked private conversations and Artifacts into Google Search results — again.** Reddit user demonstrated `site:claude.ai/share` queries surfacing real medical reports with patient names, clinical trial data, primary-school-aged kids' names and phone numbers, internal-only company docs, and employee reviews with personal info. Anthropic's line: shareable links "are not guessable or discoverable unless people choose to share them themselves" — technically true, since the leak path is third parties reposting share links somewhere crawlable, not a broken permission model. But this is not a new failure mode for them: Forbes reported the identical pattern — hundreds of indexed Claude chats — over a year ago, and Anthropic scrubbed it then too. Same bug class, same company, second time on the record. **If you use Claude's share link for anything with a real name, SSN, patient record, or minor's info in it, assume it can end up indexed. Don't rely on "nobody will find the URL" as your access control.**
- **Paperclip — an open-source control plane for running "zero-human companies" of AI agents — shipped three flaws, one at CVSS 10.0 (CVE-2026-41679).** Default config let anyone self-register without email verification, then approve their own credential challenge through the CLI auth flow, minting themselves a persistent board-level API key with nobody else's sign-off required. No account, no victim interaction, network-reachable — full control-plane takeover. Patched in 2026.416.0, now requires admin privileges for new-company imports. The pattern that keeps showing up across Ruflo, Paperclip, and everything else this class of tool ships: multi-agent orchestration platforms keep treating "who's allowed to register as an operator" as an afterthought instead of the actual security boundary.
