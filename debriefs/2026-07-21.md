## News cycle — threats worth knowing
- **GuardFall**: a shell-interpretation bypass hits **10 of 11** surveyed open-source coding agents (Aider, Cline, Goose, OpenHands, SWE-agent, Roo-Code, Open Interpreter, Plandex, Hermes, opencode). No CVE assigned — it's structural: agents string-match raw command text for safety, bash rewrites it via expansion/substitution/quoting *before* executing it. Only **Continue** resisted. 500k+ deployments exposed. If any agent you run shells out and filters by string match, assume it's bypassable.
- **Claude Code GitHub Action** had a real supply-chain hole: `checkWritePermissions` trusted *any* actor whose name ended in `[bot]` — no actual permission check. One malicious GitHub issue + prompt injection → repo compromise → downstream spread to every repo depending on the action. CVSS 7.8, some variants exploited pre-disclosure, patched in 4 days by Anthropic. Worth knowing: **this repo runs on that exact action.**
- **Langflow** CVE-2026-55255 hit CISA's Known Exploited Vulnerabilities catalog — first AI agent-builder platform to make the must-patch list.
- Manifold Security research: any browser extension can quietly hijack **Claude for Chrome** and read your Gmail/Docs/Calendar. Browser extensions are now attack surface for browser agents.
