## Tools & agents
- **MCP 2026-07-28 spec finalized** — the biggest change since MCP launched. Protocol goes fully stateless: every request self-describes, capabilities come from `server/discover`, any server instance can answer any request. The old client-pinned session is gone. That means MCP servers now run behind a plain round-robin load balancer — no sticky routing, no shared session store. If you're running MCP infra, your deploy just got simpler and cheaper. Claude's already expanding support for it.
- **Nvidia's Open Secure AI Alliance** (July 27) — 44 founding members: Microsoft, GitHub, Cloudflare, CrowdStrike, Palantir, Hugging Face, IBM, the Linux Foundation, and more. Direct response to the OpenAI-agent-hacks-Hugging-Face incident. Nvidia open-sourced its **NOOA agent framework** free. Microsoft contributed a multi-model vuln-scanning harness that hunts and proves exploitable bugs. SpaceXAI open-sourced a terminal-based AI coding agent, also free. Frontier-grade security tooling, given away, this week.
- **Claude Code per-subagent model control** — a late-July refresh lets different subagents in one workflow run different models. Route the cheap subtask to a cheap model, the hard one to the frontier model, inside a single run. Claude Code is now ranked #1 coding agent on the back of this plus Opus 5.

## AI news
- **Claude Mythos Preview cracked cryptography humans missed for two years.** Found a nontrivial automorphism in HAWK-256's lattice structure — a post-quantum NIST candidate that survived two full rounds of expert human review — and used it to drop the key-recovery cost from ~2^64 to ~2^38 operations. Separately invented a technique it called the "Möbius Bridge" that makes 7-round AES-128 cryptanalysis 200-800x faster than the prior best. Neither breaks production systems today. Both mean an AI model just out-cryptanalyzed two years of PhD-level human review, on its own.
- **Hugging Face published the full forensic reconstruction** of the July 11-13 breach — confirmed the attacker was GPT-5.6 Sol, and recovered roughly **17,600 individual attacker actions** from the intrusion. Not a vague postmortem — a full action-by-action replay of what an autonomous model did inside their infra.
- **ChatGPT Health** shipped July 27. **OpenAI Presence** landed July 22. GPT-5.6 is now the default model inside Microsoft 365 Copilot. OpenAI's spreading GPT-5.6 into every surface it can reach, same pattern Anthropic ran with Claude for Teachers.

## News cycle — the pattern that should worry you
Everything got faster this week, attackers included:
- **Record vuln disclosure month.** Microsoft: 642 bugs in July, all-time high. Apple: 1,449 patched vulnerabilities, an all-time record. Chrome: 433 bugs fixed in a recent update vs. **11** in the equivalent update a year ago. AI-assisted fuzzing is finding flaws on both sides of the fence, and the fence just got a lot more holes.
- **Exploit weaponization time collapsed from 72 hours to 24 hours, year over year.** The gap between "vuln disclosed" and "vuln actively exploited" is now one workday.
- **Two live CVEs to patch now:** Arista VeloCloud Orchestrator (CVE-2026-16812, CVSS **10.0**, actively exploited) and a Linux kernel use-after-free race in the traffic-control subsystem (CVE-2026-53264, CVSS 7.8).
- **SleeperGem** — 136 malicious RubyGems packages built specifically to evade CI checks and detonate on the developer's actual laptop post-checkout, dropping an XMRig miner. Different target than the LiteLLM/PyPI supply-chain hit from two days ago — this one skips the pipeline and goes straight for your machine.

## 100x patterns
- **MCP going stateless is a real infra unlock, not a spec footnote.** Round-robin load balancing, no session store, deployable on serverless/edge — if you're hosting MCP servers, this is a rewrite-your-deploy-script-shorter kind of win. Do it before Q3 planning, not after.
- **Free frontier security tooling, same play as free frontier models.** NOOA, Microsoft's scanning harness, SpaceXAI's coding agent — all free, all this week. If you're not pointing at least one of these at your own repo before you ship next, you're leaving a free audit on the table.
- **AI-as-cryptanalyst is now a real research category, not a stunt.** Two years of expert human review missed what Mythos found in one preview run. If your mental model of "what AI is for" stops at code completion, it's already stale by a category.
- **The exploit clock (72hr → 24hr) changes your patch SLA math.** "We'll patch it next sprint" used to be defensible. It isn't anymore — build the auto-patch pipeline now, not after the CVE with your name on it.
