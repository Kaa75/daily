## Tools & agents
- **Claude Code shipped v2.1.221 — today, literally the version running this scan.** `sandbox.network.strictAllowlist` denies non-allowlisted hosts for sandboxed commands with zero prompts — no more interactive dialog for network egress. Bigger one: `mode: "mask"` for sandbox credentials on Linux/WSL — sandboxed commands read a sentinel stand-in for your credential files, and the real values get substituted back in only at the sandbox proxy on egress, with regex-based partial extraction if you need it. That means an agent running inside the sandbox never actually holds your real secret in memory. Falls back to hard `deny` on macOS. Also: a `DirectoryAdded` hook, a VSCode focus-view toggle (`Ctrl+Alt+F`), and a `prompt-audit` subcommand for the `claude-api` skill.
- **GitHub Copilot dropped Gemini 2.5 Pro and Gemini 3 Flash** (Jul 31, server-side, no opt-out) — replacements are Gemini 3.1 Pro and Gemini 3.5 Flash. If a script or saved model pref still points at the old names, it silently stops routing.

## AI news
- **Microsoft's Project Perception entered public preview yesterday (Aug 3), live inside Defender.** First in-house cybersecurity model, MAI-Cyber-1-Flash — a compact, code-tuned derivative of their MAI-Thinking-1 line, trained on Microsoft's own exploit/remediation history. 96% on CyberGym, ~50% cost cut vs. the current Defender config, and it routes the genuinely hard cases up to GPT-5.4. Three agent roles: red (maps attack paths), blue (triages what's real risk), green (actually fixes it). This is a security team built entirely out of agents, shipping to production accounts starting now.
- **Claude Opus 4.1 retires from the API tomorrow (Aug 5).** If anything in your stack still pins `claude-opus-4-1-20250805`, that's a 24-hour warning, not a heads-up for next week.

## News cycle — the vendor whose model is writing this told you it's not a bug
- **GhostApproval — fifth instance this summer of "the confirm dialog lies to you," and this time Anthropic said no.** Wiz found a symlink flaw across six coding assistants: Amazon Q, Claude Code, Augment, Cursor, Google Antigravity, Windsurf. Mechanism: a repo file like `project_settings.json` is actually a symlink to something real — `~/.ssh/authorized_keys`, say. The agent follows the link, writes to the real target, but the approval prompt only ever shows the harmless local filename. Amazon (CVE-2026-12958), Cursor (CVE-2026-50549), and Google all treated it as a vulnerability and patched. Augment and Windsurf went quiet with no fix. **Anthropic disputed it outright** — ruled it "outside our threat model," on the logic that a user who trusts a directory owns the consequences of approving an edit inside it, though they quietly shipped a symlink warning in Claude Code v2.1.32 back in February. Read that lineup again: same root cause as DeepJack and DuneSlide, four other vendors called it real, and the company whose model is generating this file told researchers their own tool doesn't need fixing.
- **EU AI Act's high-risk provisions became "enforceable" Aug 2** — Articles 9-17 and 26, conformity assessments, CE marking, the €15M/3%-revenue penalty tier, all live on paper. Except the Digital Omnibus, a provisional agreement from May 7, would push the actual Annex III deadline out to Dec 2, 2027 — and that agreement isn't formally law yet. So right now the legal answer to "is this enforced" is genuinely unsettled, two days after the date everyone quoted as the deadline.
