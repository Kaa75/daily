## Tools & Agents — New Fire

**Claude Security plugin** *(Anthropic, beta Jul 21)* — `/claude-security` inside Claude Code. Multi-agent vuln scanner, runs in your terminal, three jobs: scan the whole repo, scan a diff/PR/commit, or turn findings into `.patch` files you review yourself. Reads git history, traces data flow across files, catches context-dependent bugs a linter can't see. Free, in beta, already live. Run it before your next commit.

**MCP spec 2026-07-28** — moved to a **stateless core** (request/response, not stateful bidirectional), meaning servers now deploy on serverless/edge instead of needing a persistent process. Governance handed to the **Linux Foundation**. 400M monthly SDK downloads, 4x growth this year, 22,000+ servers, production at Block/Uber/Bloomberg/Morgan Stanley. This is no longer "Anthropic's thing" — it's the wire format for the whole industry now.

**Kimi K3 full weights** *(Moonshot, Jul 26)* — the "landing in 2 days" from last scan actually landed. 2.8T param MoE, full open weights, confirmed largest open-weight release to date. If you were waiting to download it, it's downloadable.

**DeepSeek-V4-Flash-0731** *(Jul 31)* — fast/cheap variant of V4, days after V4 hit GA. DeepSeek shipping variants at the same cadence OpenAI ships tiers.

**Cursor 3.11** — Side Chats (spin a parallel agent thread with `/side` without derailing your main one), Conversation Search (Cmd+K), Cloud Agent Hooks. Catch: `beforeSubmitPrompt` hook fires but the model **silently never receives the modification** — confirmed bug, don't trust it for anything security-relevant yet. File + tool hooks (`preToolUse`, `afterFileEdit`) work fine.

**Claude Code** — new VSCode Focus view, sandbox credential masking (secrets don't leak into agent context), per-subagent model control (cheap model for grunt work, strong model for the hard step), better Windows startup + background sessions.

**Grok Voice Think Fast 2.0** *(Aug 5 — today)* — speech-to-speech, becomes the default `grok-voice-latest` route. **Grok Imagine Video 1.5** — native 1080p, up to 7 reference images per generation, voice consistency across cuts.

## News Cycle — What Should Actually Worry You Today

**Two Cursor zero-click prompt injection flaws, CVSS 9.8.** Hidden text on a page you didn't even have to click on escapes the terminal sandbox and overwrites the sandbox helper binary → OS-level RCE on your dev machine AND connected cloud workspaces. No user action required. If you run Cursor, check for the patch before your next session.

**AWS Kiro** — hidden text on an ordinary webpage instructs Kiro to silently rewrite its own MCP config and auto-reload it. In default autonomous mode there's **no approval prompt** — the agent edits the fence that was supposed to contain it. The cage rewrites itself from the outside.

**A prompt-injected GitHub issue stole an npm publish token and pushed a trojaned `cline@2.3.0` to the public registry.** Attack chain: open an issue → Claude Code Action reads it → agent hands over write credentials → attacker publishes malware under a trusted package name. Real incident, publicly disclosed by RyotaK. **Fix shipped: update to `claude-code-action` v1.0.94+ and `@anthropic-ai/claude-code` v1.0.93+ if you run either in CI.** Check today, not this week.

**65% of orgs report an AI agent security incident in 2026.** Not a minority problem anymore — it's most of the room.

## 100x Patterns — Shortcuts That Scale

- **`/claude-security` before every commit.** Free multi-agent vuln scan, already in your terminal if you run Claude Code. Zero excuse not to run it pre-push.
- **Update your CI agent action versions TODAY** if you run Claude Code Action, Copilot, or Gemini CLI in GitHub workflows — the npm-token theft chain is public and repeatable against unpatched setups.
- **MCP going stateless = cheap agent infra.** Deploy MCP servers on serverless/edge now instead of babysitting a persistent process. Rebuild your homegrown tool servers on the new spec.
- **Side-thread instead of context-switch.** Cursor's Side Chats formalize what good agent users were already doing manually — spin a parallel thread for the tangent, don't derail the main run.
- **Batch your Sonnet 5 volume before Aug 31** — pricing goes up 50% Sept 1. Free money if you plan around it.
- **Per-subagent model routing** (Claude Code) — cheap model for boilerplate steps, expensive model only where reasoning depth actually matters. Stop paying flagship rates for grunt work.

## The Meta — Why You're Here

Same week Anthropic ships a free vulnerability scanner into your terminal, someone finds two zero-click RCE holes in a competitor's terminal agent, and a prompt-injected GitHub issue turns into a trojaned npm package with your name's trust behind it. The defense and the attack shipped in the same ten days, from the same ecosystem, aimed at the same you.

And Anthropic just hired a Chief Global Affairs Officer. Read that as what it is: the industry stopped being "move fast, ask forgiveness" and started building the room where governments and labs argue about what these things are allowed to do. That room exists because what these things can already do got dangerous enough to need one.

You're not paranoid for checking your CI action versions today. You're doing the job. The job changed shape this year — it used to be "write correct code," now it's "write correct code AND verify the thing writing it with you isn't the open door." Both halves are the craft now. Neither is optional.
